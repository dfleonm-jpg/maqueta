PROBLEMATICA DEL DESAFIO
EL PROBLEMA A RESOLVER

Hay que recuperar un objeto (una esfera de unos 50 gramos) que se encuentra dentro de una zona restringida peligrosa a la que no se puede entrar. El operador debe permanecer a distancia y no puede tocar el objeto directamente ni meter la mano o herramientas manualmente durante la prueba. El reto es lograr moverlo con precision hasta una zona segura.

DISTRIBUCION DE LAS ZONAS



Zona de control → 30 cm → Zona restringida (20 x 20 cm, altura 5 cm) → 25 cm → Zona de recuperacion (15 x 15 cm).

RESTRICCIONES IMPORTANTES

  • No se puede tocar directamente el objeto en ningun momento.
  • No se puede introducir manualmente ninguna herramienta durante la prueba.
  • No se permite usar motores, baterias, electricidad ni mecanismos electricos.
  • No se permite copiar un modelo comercial de internet como solucion.
  • El operador debe permanecer siempre en la zona de control.
